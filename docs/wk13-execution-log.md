## Defect ที่พบและแก้ระหว่างรอบทดสอบ

- Regex ใน seed สูตรน้ำตาล escape ซ้ำ ทำให้ไม่สร้าง rule สำหรับระดับหวาน 25–100%; แก้รูปแบบ regex แล้วเริ่มฐานข้อมูลทดสอบใหม่และทดสอบการหัก/คืนครบทุกระดับ
- API อัปโหลดรับ `text/plain` แล้วบันทึกเป็นไฟล์ `.png`; เพิ่ม allowlist MIME, ตรวจ signature ของ PNG/JPEG/WEBP/GIF และจำกัดขนาด 15 MB; ทดสอบไฟล์ PNG จริงผ่านและข้อมูลที่ไม่ใช่ภาพถูกปฏิเสธ
- Cart checkout ไม่ส่งชื่อ options ไปกับ IDs และ server เคยบันทึกชื่อจาก client ที่อาจว่าง; ให้ backend อ่านชื่อจาก option IDs แล้วบันทึก snapshot ที่ยืนยันจากฐานข้อมูล
- Cart, Barista queue และ Owner ledger ตัดชื่อความหวานเหลือแค่คำว่า “หวาน” หรืออ่านเฉพาะ JSON รูปแบบเก่า; ปรับให้แสดงเปอร์เซ็นต์ชัดเจนและรองรับ option schema ปัจจุบันพร้อมข้อมูล legacy; ยืนยันบน order #015 ว่าแสดง `หวาน 25%`

## ขอบเขตของผล

ผลนี้ยืนยัน flow UI ที่ระบุและ test cases ตาม matrix บนสภาพแวดล้อมจำลองเท่านั้น ไม่ได้วัด performance/load, concurrency, usability กับพนักงานจริง หรือความเข้ากันได้ของทุก browser/device. การตรวจภาพ upload ครอบคลุม PNG จริงและ input ชนิดผิด/ลายเซ็นไม่ตรง; ยังไม่ได้ทดสอบไฟล์ JPEG, WEBP, GIF และขนาดขอบเขต 15 MB แยกทุกชนิด.
