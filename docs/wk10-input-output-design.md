**1.3 หลัก Usability Heuristics ที่ใช้ในการสร้างตารางนี้**

| **Heuristic**                  | **หลักออกแบบ Input ที่เกี่ยวข้อง** | **การใช้ในฟอร์ม POS**                                                                        |
|--------------------------------|------------------------------|--------------------------------------------------------------------------------------------|
| Error Prevention               | Field Type, Default Value    | ปุ่มยืนยันปิดจนกว่าข้อมูลครบ stepper จำนวนหยุดที่ 1 ไม่สามารถกรอกติดลบหรือศูนย์ได้ ขนาดและวิธีชำระเงินบังคับเลือก |
| Visibility of System Status    | Immediate Feedback           | แสดงสาขา ยอดรวม จำนวนรายการ และสต็อกคงเหลือตลอดเวลา ข้อความ loading และผลบันทึกหลังกดยืนยัน        |
| Recognition Rather Than Recall | Field Type ที่เหมาะสม          | เลือกเมนู ขนาด ความหวาน ท็อปปิง และวิธีชำระเงินด้วยปุ่มที่เห็นตรงหน้า ไม่ต้องจำชื่อเมนูหรือรหัส                 |

**1.4 Validation การตรวจสอบความถูกต้อง**

ตรวจสอบข้อมูลก่อนบันทึกทั้งฝั่ง client และฝั่ง server เช่น จำนวนสินค้าที่สั่งต้องเป็นจำนวนเต็มบวก ไม่สามารถสั่ง -1 แก้วหรือ 0 แก้วได้ การตรวจสอบซ้ำสองชั้นแบบนี้คือหลักการ Defense in Depth คือไม่พึ่งการป้องกันชั้นเดียว ฝั่ง client จะมาช่วยประสบการณ์ในฝั่งของผู้ใช้ ส่วนฝั่ง server ต้องตรวจซ้ำเสมอเพราะ request อาจถูกส่งตรงโดยไม่สนใจ Ui ตามที่ข้อมูลในเรื่อง createOrder

| **เรื่องที่ต้องการตรวจสอบ**                                 | **ฝั่ง client**           | **ฝั่ง server**                                                      | **ที่มา**                             |
|--------------------------------------------------------|-------------------------|--------------------------------------------------------------------|-------------------------------------|
| ต้องมีรายการอย่างน้อย 1                                    | ปุ่มยืนยันปิดอยู่              | HTTP 400 "ไม่มีรายการสินค้า"                                           | FR-03                               |
| menuId ต้องเป็นตัวเลข มีอยู่จริง และเป็นเมนูของสาขาเดียวกับออเดอร์ | เลือกจากการ์ดเมนูเท่านั้น     | HTTP 400/404 "ไม่พบเมนู"                                             | FR-01; menu_item.branch_id          |
| quantity เป็นจำนวนเต็ม \> 0                              | stepper ต่ำสุด 1          | HTTP 400 "จำนวนต้องเป็นจำนวนเต็มบวก"                                  | order_item.quantity                 |
| quantity ต้องไม่เกินสต็อก                                  | เตือนทันทีเมื่อเกินตัวเลขที่แสดง | HTTP 409 "วัตถุดิบไม่พอ"                                               | US-03 AC3; menu_item.stock_quantity |
| ต้องเลือกขนาด                                            | ปุ่มเพิ่มปิด + ข้อความเตือน    | HTTP 400 "ข้อมูลไม่ครบ"                                               | US-02 AC2, US-03 AC2                |
| payment_method ต้องเป็น cash, transfer หรือ qr            | เลือกจากปุ่ม 3 ปุ่ม          | HTTP 400 "วิธีชำระเงินไม่ถูกต้อง"                                        | FR-06                               |
| ราคาต่อหน่วยห้ามรับจาก client                              | แสดงราคาเพื่อดูเท่านั้น       | server อ่านราคาจาก menu_item.price แล้วบันทึกเป็น order_item.unit_price | FR-05;ไฟล์ schema                    |
