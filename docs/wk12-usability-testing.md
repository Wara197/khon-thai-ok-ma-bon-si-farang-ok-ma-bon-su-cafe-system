# รายงานผลการทดสอบการใช้งานระบบ (Usability Testing Report)

## โครงการ: ระบบจุดขายและจัดการร้านกาแฟ (Coffee Shop POS System)

**สัปดาห์:** สัปดาห์ที่ 12 — การทดสอบการใช้งานและประเมินผล (Usability Testing & Evaluation)  
**ทีมผู้พัฒนา:** ทีม 2 คนไทยออกมาบ่งชี้ ฝรั่งออกมาบ่งชู้  
**รายวิชา:** 88734065 การวิเคราะห์และออกแบบระบบ  
**เกณฑ์อ้างอิง:** NFR-03 (ผู้ใช้ใหม่สร้างออเดอร์สำเร็จอย่างน้อย 4 ใน 5 ครั้ง หลังรับคำแนะนำไม่เกิน 5 นาที)

> **สถานะหลักฐาน:** คะแนน/เวลา/จำนวนผู้ทดสอบด้านล่างเป็นข้อมูลที่บันทึกไว้ในกิจกรรม wk12 ไม่สามารถตรวจย้อนกลับจาก source code และยังไม่ได้เก็บซ้ำในการ reverse-engineering รอบนี้ จึงไม่ถือเป็นผลทดสอบที่ revalidated หรือเป็นการยืนยัน usability ของ build ปัจจุบัน

## 1. วัตถุประสงค์และขอบเขตการทดสอบ (Objectives & Scope)

การทดสอบ Usability Testing ครั้งนี้ มีวัตถุประสงค์เพื่อ:

1. ประเมินความยากง่ายในการใช้งาน (Learnability & Ease of Use) ของหน้าจอระบบ POS ทั้งฝั่ง Cashier และ Barista
2. วัดอัตราความสำเร็จในการทำภารกิจ (Task Completion Rate) และเวลาเฉลี่ยที่ใช้ (Time on Task)
3. ตรวจสอบการผ่านเกณฑ์ข้อกำหนดด้านคุณภาพ **NFR-03**
4. วัดระดับความพึงพอใจของผู้ใช้ด้วยแบบประเมินมาตรฐานสากล **System Usability Scale (SUS)**

## 3. ภารกิจการทดสอบ (Testing Tasks & Scenarios)

ผู้ทดสอบจะได้รับคำแนะนำการใช้งานเบื้องต้นเป็นเวลา 3 นาที จากนั้นให้ปฏิบัติภารกิจ 4 งานติดต่อกัน โดยไม่มีการชี้แนะเพิ่มเติม:

- **Task 1 (เลือกเมนูและตัวเลือก):** ค้นหาเมนู "Iced Caramel Macchiato" เลือกขนาด Large (L), ความหวาน 50%, เพิ่มท็อปปิง "วิปครีม" แล้วเพิ่มลงตะกร้า
- **Task 2 (ปรับปรุงตะกร้าสินค้า):** ปรับจำนวนสินค้าในตะกร้าเป็น 2 แก้ว และตรวจสอบยอดรวมราคาสินค้าที่คำนวณอัตโนมัติ
- **Task 3 (ชำระเงินและรับเลขคิว):** กดปุ่มชำระเงิน เลือกวิธีชำระ "PromptPay QR" กดยืนยันชำระเงิน และตรวจสอบใบเสร็จพร้อมเลขคิว
- **Task 4 (จัดการคิวฝั่งบาริสต้า):** สลับไปยังหน้าจอ Barista Screen ตรวจสอบออเดอร์ที่เพิ่งสร้าง และกดเปลี่ยนสถานะจาก "รอทำ (Pending)" เป็น "กำลังทำ (In Progress)" และ "เสร็จสิ้น (Completed)"

## 5. การประเมินความพึงพอใจด้วย System Usability Scale (SUS)

ผู้เข้าร่วมทดสอบตอบแบบสอบถามมาตรฐาน SUS จำนวน 10 ข้อ (เกณฑ์คะแนน 1–5):

| ข้อที่ | คำถามประเมิน SUS                                                     | ค่าเฉลี่ยคะแนน (1–5) |
| :----: | -------------------------------------------------------------------- | :------------------: |
|   1    | ฉันคิดว่าจะอยากใช้ระบบนี้เป็นประจำในการทำงาน                         |         4.6          |
|   2    | ฉันพบว่าระบบนี้มีความซับซ้อนเกินความจำเป็น (Negative)                |         1.4          |
|   3    | ฉันคิดว่าระบบนี้ใช้งานง่ายและไม่ยุ่งยาก                              |         4.8          |
|   4    | ฉันคิดว่าจะต้องมีเจ้าหน้าที่เทคนิคคอยช่วยเหลือในการใช้งาน (Negative) |         1.2          |
|   5    | ฟังก์ชันและส่วนประกอบต่าง ๆ ของระบบมีความสอดคล้องกันดี               |         4.6          |
|   6    | ฉันรู้สึกว่ามีสิ่งที่ไม่สอดคล้องกันหรือชวนสับสนในระบบ (Negative)     |         1.4          |
|   7    | ฉันคิดว่าคนส่วนใหญ่จะสามารถเรียนรู้ระบบนี้ได้อย่างรวดเร็ว            |         4.8          |
|   8    | ฉันรู้สึกว่าระบบนี้ใช้งานยากและไม่คล่องตัว (Negative)                |         1.2          |
|   9    | ฉันมีความมั่นใจสูงมากในการใช้งานระบบนี้                              |         4.6          |
|   10   | ฉันต้องเรียนรู้สิ่งใหม่ ๆ จำนวนมากก่อนที่จะใช้งานระบบได้ (Negative)  |         1.4          |

### การคำนวณคะแนน SUS Score รวม:

$$\text{Score} = \left[ \sum(\text{Odd items} - 1) + \sum(5 - \text{Even items}) \right] \times 2.5$$
$$\text{Score} = [(3.6 + 3.8 + 3.6 + 3.8 + 3.6) + (3.6 + 3.8 + 3.6 + 3.8 + 3.6)] \times 2.5 = 34.8 \times 2.5 = \mathbf{87.0}$$

> **ผลการประเมิน SUS:** ได้คะแนนรวม **87.0 คะแนน (เต็ม 100)**  
> อยู่ในระดับ **Grade A (Excellent / Best Imaginable)** ซึ่งบ่งชี้ว่าระบบมี UX/UI ที่เป็นมิตร ใช้งานง่าย และมีความชัดเจนสูงมาก

## 6. ข้อเสนอแนะและข้อคิดเห็นจากผู้ใช้งาน (User Feedback)

### ข้อดีที่ผู้ใช้ชื่นชอบ:

1. การ์ดเมนูมีรูปภาพที่ชัดเจน สีสันสบายตา และแบ่งแท็บหมวดหมู่ชัดเจนทำให้หาของง่าย
2. หน้าต่างเลือกตัวเลือก (Option Modal) แยกหมวดขนาด ความหวาน และท็อปปิงอย่างเป็นระเบียบ และแสดงราคาบวกเพิ่มทันที
3. หน้าจอบาริสต้าเห็นข้อมูลคิวชัดเจน การกดเปลี่ยนสถานะตอบสนองฉับไวไม่ต้องรอโหลดนาน

### ข้อเสนอแนะเพื่อปรับปรุงในเวอร์ชันถัดไป:

1. ควรเพิ่มปุ่มค้นหาเมนูด้วยการพิมพ์ตัวอักษร (Search Box) สำหรับร้านที่มีรายการเมนูจำนวนมาก
2. เพิ่มเสียงแจ้งเตือน (Audio Alert/Beep) ที่หน้าจอบาริสต้า เมื่อมีออเดอร์ใหม่ถูกส่งเข้ามา
